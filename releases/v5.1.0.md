# v5.1.0

Adds native C/C++, Kotlin/JVM, C#, Python, and TypeScript/JavaScript libraries alongside Swift. All implementations use the same bundled rule catalogue and provide catalogue lookup, raw inference, guessing, common-prefix queries, typed grammatical forms, and asynchronous APIs using language-appropriate conventions.

## Packages

- SwiftPM: Git tag `v5.1.0` in `ShingZhanho/FRConjugation`.
- C/C++: source and platform-specific native archives attached to this release; compatible ICU libraries are required.
- Kotlin/JVM: `com.jacobshing:frconjugation:5.1.0` on Maven Central.
- C#: `ShingZhanho.FRConjugation` on NuGet.
- Python: `jacobszh-frconjugation` on PyPI; import `frconjugation`.
- TypeScript/JavaScript: `@jacobshing/frconjugation` on npm.

## Compatibility

The Swift public API is unchanged from v5.0.1. Swift sources now live under `swift/`, while the root remains a Swift package. The shared binary catalogue lives in `catalogue/` and retains the same conjugation data.

Consumers of unreleased development ports must update the former `com.jacobs` Kotlin package to `com.jacobshing`, the former `JacobS.FRConjugation` C# namespace/package to `ShingZhanho.FRConjugation`, and the development npm/PyPI package names to those listed above. These are the first registry releases of those ports.

## Distribution

Release builds validate every language implementation, shared catalogue compilation, and Maven signatures. Native libraries are checked on macOS and Linux. Registry publication runs through the manual GitHub Actions publishing workflow; source archives, rule files, and SHA-256 checksums accompany the GitHub release.
