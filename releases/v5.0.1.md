- Added `commonPrefix(_:homonymIndex:)`, `rawInferredCommonPrefix(_:homonymIndex:)`, and `guessCommonPrefix(_:homonymIndex:)`, with synchronous and asynchronous overloads.
- Prefixes compare main-verb spellings across all supported slots and alternatives, preserving accent differences and excluding auxiliaries and pronouns. Catalogue lookup uses available forms, raw inference predicts forms, and guessing fills each missing catalogue slot.
- An empty string is a valid result for verbs such as *aller*. Unavailable results return `nil`.

## Breaking API removals since v5.0.0

The deprecated cache APIs and previously unavailable custom-model loaders have been removed completely. Code using cache APIs requires changes.

- Omit `cacheSize:` from initialization, `getShared()`, and `load()`.
- Remove references to `defaultCacheSize`, `cacheCount`, and `cacheCapacity`, and calls to `clearCache()`.
- Use the bundled loaders `Conjugator()`, `Conjugator.getShared()`, and `try await Conjugator.load()`. The `modelDirectory:` overloads have been deleted.

This release retains the requested 5.0.1 version number despite these source-breaking removals.
