This prerelease removes 16 declarations from `Conjugator`. Code that used the deprecated cache APIs requires a source change.

- Drop the `cacheSize:` argument from `Conjugator(...)`, `getShared(...)` (sync or async), and `load(...)`. Use `Conjugator()`, `Conjugator.getShared()`, or `try await Conjugator.load()`.
- Remove references to `Conjugator.defaultCacheSize`, `cacheCount`, and `cacheCapacity`, and delete calls to `clearCache()`. The rule engine has no prediction cache.
- The eight `modelDirectory:` initializers and loaders for `String` and `URL`, with and without `cacheSize:`, have been deleted. These already failed to compile in v5.0.0.

The conjugation rules and bundled catalogue are identical to v5.0.0.
